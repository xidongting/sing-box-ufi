# 首版确认规格

来源：本次用户需求澄清，2026 年；本轮仅本地开发，远程创建/发布与设备验证另行确认。

- 独立 sing-box-ufi 仓库，不修改 UFI-TOOLS。插件是 interface，原生 sing-box 是独立内核；不分叉内核、不另起 Web 后台。
- 目标是已 Root、UFI Tools v4.1.5 的 Android U30 Air 与 F50。仅 U30 Air 是最低实机验收目标；本轮不连接设备，均不得标记已实测。
- 每天检查官方稳定及 alpha/beta/RC Release，仅新版本构建，允许手动指定官方已发布 tag。不追主分支提交。采用对应上游官方 Android CLI 构建参数、功能标签、工具链。产物带 SHA-256、源码身份和许可证。
- 插件与内核独立版本/发布。提供 UFI Tools 可导入的 JS 插件文件及自定义插件源，用户可选择旧版内核。
- 插件功能：环境检测、安装/升级、版本/状态、启动/停止/重启、防重复启动、单份 JSON 编辑/导入/校验、日志、默认关闭的开机自启、卸载。删除配置另行确认。
- 用户自行提供原生 config.json。保存前由 sing-box check 校验，失败不覆盖，成功保存不重启。固定且公开工作目录；外部证书、规则集等文件由用户自行管理。
- 所有网络行为由 sing-box 原生配置及设备能力决定。插件不配置 TProxy、TUN、路由、防火墙、DNS 劫持，也不限制原生内核功能。无订阅转换/管理、节点选择器、流量图表或额外 Dashboard。
- 设备升级只能手动点击。完整下载且校验成功后停止旧实例，替换内核；完成后始终停止，启动由人操作。不恢复现场、不迁移配置、不自动回滚、不做网络健康检查，也不以配置校验阻止升级。
- 升级保留配置、自启偏好。下次重启仍按自启偏好运行。关闭页面不停止；异常退出保留日志，不自动重启。
- 只做轻量测试：管理命令接口与发布产物接口，JS 语法/类型与最小加载检查。最终实机验收另行执行，覆盖 U30 Air 安装、配置校验、实际连接、启停、升级后停止、自启。
- 本地代码审查以初始空提交为基线，Standards/Spec 双轴；完成后本地提交，不推送、不创建远程仓库。
