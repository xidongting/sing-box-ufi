# 本地首版自审

范围：初始空提交 `6e14676` 至首版 `7bf2bae`，以及本次修复。用户批准在当前会话自审，替代因 Pi 后台依赖缺失而未启动的两个 reviewer。本报告不是独立审查，也不是设备验收。

## Standards

发现并修复 1 项接口可靠性问题：

- **大配置超出 Shell 单参数限制。** 编辑器允许 512 KiB，但 Base64 全文被包进 `sh -c` 的一个参数。新增 220 KiB 配置接口测试先复现失败；现在每次最多传输 32 KiB Base64，私有临时文件解码后经原有 `manager.sh save` 校验。逐字节回归检查确认内容不变，完成或失败后清理临时文件。没有改变配置格式或增加服务。

额外核对：Shell 引用、认证接口、输出使用 textContent、SHA-256、Root 目录权限、PID 对应可执行文件、失败清理、卸载二次确认。未发现需要新增抽象的重复代码或明显范围外功能。

## Spec

发现并修复 3 项发布链路问题：

1. **各渠道最新版本依赖 GitHub 返回顺序。** 原实现取首条记录，不能保证是最新版本。改为按数字版本与 alpha/beta/rc 序号选择，补无序列表回归测试。
2. **构建链接参数并非完全跟随上游。** 原实现固定追加 `-s -w -buildid=`，旧版官方 Android CLI 参数不同。现在提取完整 `-ldflags`，仅替换版本占位符并展开官方共享参数；未知构建参数/目标选项明确失败。测试覆盖旧版、新版、未知参数拒绝路径。额外用官方 v1.12.0、v1.14.4 的真实 workflow/SDK 文件验证提取结果。
3. **源码交付缺少当前构建脚本快照。** 内核 Release 现在同时带上此次仓库提交的脚本归档与 SHA-256，配合对应上游与 vendor 源码包。未执行实际 Release，归档/上传仍待远程构建验证。

确认保持：手动设备升级、升级后停止、不按配置兼容性阻止替换、不迁移、不回滚、自启偏好不变、原生单配置、无网络接管。U30 Air/F50 均保持“未实测”标注。

## 验证结果

- 14 项 Python 测试在 Linux 容器通过，包含真实独立 C 测试进程的启停/升级生命周期；该进程不是 sing-box。
- 2 项 JS 插件接口/加载检查通过。
- TypeScript checkJs、JS 语法、ShellCheck、actionlint、git diff --check 通过。
- 官方 v1.12.0 与 v1.14.4 构建设置提取通过；未下载完整依赖并编译 Android 内核。

## 已知限制

- 未访问设备、未运行远程 Actions、未创建或推送公开仓库；不承诺实机或端到端构建可用。
- 本地 UFI Tools 源码用于核对接口，不能代替设备上 v4.1.5 固件行为验证。
- Root Shell 可能把命令及配置写入 UFI Tools 自身调试日志；README 已警告，插件无法替上游关闭该记录。
- 日志只在启动时轮转；管理进程被强制终止可能留下锁；README 记录处理限制。
- 上游 workflow 结构改变时仍需维护适配器；本次只覆盖已识别的 Android CLI 构建形态，不自动执行任意上游脚本。

结论：Standards 1 项、Spec 3 项发现均已处理；尚未完成的远程构建及实机验证属于用户明确暂缓范围。
