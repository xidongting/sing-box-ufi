# sing-box-ufi

Builds from official sing-box source + a native UFI Tools management plugin.

## Usage

1. Download [sing-box-ufi.js](https://github.com/xidongting/sing-box-ufi/releases/latest/download/sing-box-ufi.js).
2. Import it in **UFI Tools → Plugin Management**, save, and refresh the page.
3. Open **sing-box** in the toolbar, check the environment, and load available core versions.
4. Select a version and click **Install / Upgrade**.
5. Paste or import your native `config.json`, click **Validate and Save**, then **Start**.

After an upgrade, start sing-box manually. Enable boot startup if needed.

Alternatively, add this URL as a custom plugin source:

```text
https://github.com/xidongting/sing-box-ufi/releases/latest/download/plugins.json
```
